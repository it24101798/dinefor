# DineFor MVP - MERN Starter

DineFor is a hotel buffet and dining experience reservation marketplace.

## Structure

- `client/` - React + Vite frontend
- `server/` - Node.js + Express backend

## Quick Start

### Backend
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

## MVP Modules

- User authentication
- Hotel listings
- Buffet listings
- Booking system
- Admin dashboard placeholder
- Hotel dashboard placeholder
